01 / HOW IT WORKS

سير عمل موحد، مع احترام قواعد كل متجرOne workflow, each store's own rules

01

جهّز مرة واحدةPrepare once

بيانات التطبيق، الصور، وصف المتجر، رقم الإصدار وملف البناء ضمن مساحة آمنة.Organize app details, store assets, release notes, version numbers, and build files.

02

اختر المتاجرChoose destinations

حدد المتاجر التي يملك المطور حساباً وصلاحية نشر فيها، بعد تفعيل ربطها رسمياً.Select stores where the developer has an eligible publisher account and has authorized the integration.

03

أرسل وتابعSubmit and track

متابعة رفع الحزمة وإرسال المراجعة ونتائج كل متجر بصورة مستقلة.Track package upload, review submission, and each store's result independently.

02 / OFFICIAL CONNECTORS

التكاملات التي نبدأ بدراستهاOfficial integrations to evaluate first

01 / ANDROID

Google Play

واجهة Publishing API تتيح رفع الإصدارات وإدارة مسارات النشر، بعد أن يمنح مالك التطبيق حساب الخدمة الصلاحيات اللازمة.The Publishing API supports release uploads and track management when the app owner grants the required account permissions.

Official API documentation ↗Integration candidate · Not connected
02 / APPLE

Apple App Store Connect

توفر API إدارة بيانات التطبيق والإصدارات والإرسال للمراجعة. رفع ملفات البناء يعتمد على Transporter أو Xcode مع مفاتيح API.The API manages app metadata, versions, and review submissions. Build uploads use Transporter or Xcode with API keys.

Official API documentation ↗Integration candidate · Not connected
03 / HUAWEI

Huawei AppGallery

توفر AppGallery Connect واجهات لرفع ملفات التطبيق وتحديث بياناته وإرسال الإصدارات للنشر والمراجعة.AppGallery Connect provides APIs for uploading packages, updating listing information, and submitting releases for review.

Official API documentation ↗Integration candidate · Account access required

هذه المتاجر مرشحة للتكامل وليست متصلة حالياً. لا يمكن ضمان النشر الآلي أو تجاوز مراجعة المتجر؛ كل مطور يحتاج إلى حساب ناشر صالح، ومفاتيح وصلاحيات رسمية، وموافقة المتجر على التطبيق.These are integration candidates, not active connections. Automated submission cannot bypass store review. Each developer needs an eligible publisher account, authorized credentials, and store approval.

03 / SECURITY & CONTROL

حساباتك تبقى تحت سيطرتكYour publisher accounts stay yours

سيكون الربط بتفويض رسمي من صاحب التطبيق. ستُخزن الأسرار المشفرة على الخادم فقط، مع صلاحيات محدودة وسجل للعمليات وإمكانية إلغاء الربط. لن نطلب مشاركة كلمات المرور، ولن نعرض مفاتيح API في المتصفح.Connections will be authorized by the app owner. Secrets will be encrypted server-side with scoped permissions, audit logs, and revocation. We will never ask for account passwords or expose API keys in the browser.
