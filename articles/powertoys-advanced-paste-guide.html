PowerToys Advanced Paste: تحويل النصوص والصور والوسائط من الحافظة بأمانPowerToys Advanced Paste: Transform Clipboard Text, Images, and Media

نُشر في 24 نوفمبر 2026 · آخر تحديث 24 نوفمبر 2026 · قراءة نحو 8 دقائقPublished November 24, 2026 · Last updated November 24, 2026 · About 8 min read

شرح عملي لأداة Advanced Paste في PowerToys، واختصاراتها وميزات OCR والتحويل المحلي وخيارات الذكاء الاصطناعي وتكاليفها.A practical guide to PowerToys Advanced Paste, its shortcuts, local OCR and media conversion, optional AI providers, and their costs.

النسخة العربية

لماذا تستحق الحافظة أداة مستقلة؟

تتعامل الحافظة في Windows عادة مع النسخ واللصق، لكن العمل اليومي يتطلب أحياناً إزالة التنسيق، أو تحويل جدول إلى JSON، أو استخراج نص من صورة، أو حفظ محتوى منسق في ملف. تضيف أداة Advanced Paste في Microsoft PowerToys طبقة تحويل فوق الحافظة، بحيث لا تضطر إلى فتح محرر منفصل لكل عملية صغيرة.

تظهر نافذة Advanced Paste بالاختصار الافتراضي Win + Shift + V. وتسمح باختيار صيغة أو إجراء، مع إمكانية ضبط اختصارات مباشرة لبعض المهام. الأداة جزء من مجموعة PowerToys المفتوحة المصدر، وليست خدمة سحابية مستقلة؛ لكن بعض الوظائف الاختيارية تستدعي مزود ذكاء اصطناعي تختاره أنت.

تثبيت PowerToys والتحقق من الإصدار

تدعم وثائق Microsoft تثبيت PowerToys على Windows 11 أو Windows 10 الإصدار 2004 (البنية 19041) أو أحدث، مع معالج x64 أو ARM64. يمكن تثبيته من Microsoft Store أو صفحة GitHub الرسمية أو باستخدام WinGet. من PowerShell نفّذ: winget install --id Microsoft.PowerToys --source winget. بعد التثبيت افتح PowerToys Settings وابحث عن Advanced Paste وفعّلها.

في تاريخ المراجعة 24 نوفمبر 2026، تعرض صفحة الإصدارات الرسمية الإصدار المستقر v0.102.3101.0، المنشور في 6 نوفمبر 2026، بينما تظهر إصدارات v0.103 ضمن المعاينات التطويرية. لا تثبّت إصدار Preview على جهاز العمل لمجرد أنه يحمل رقماً أعلى؛ اختر Release المستقر، ثم راجع صفحة الإصدارات عند تحديث هذا الدليل لأن الأرقام تتغير.

تحويل النصوص دون الذكاء الاصطناعي

من الاستخدامات الأساسية اللصق كنص عادي لإزالة التنسيق الذي يأتي من صفحات الويب أو مستندات Office. وتوفر الأداة أيضاً التحويل إلى Markdown أو JSON، وحفظ المحتوى في ملفات TXT أو HTML أو PNG بحسب نوع البيانات. على سبيل المثال، يمكن تحويل نص منسق إلى Markdown قبل وضعه في مستودع توثيق، أو حفظ HTML منسوخ في ملف مستقل بدلاً من إعادة بناء الصفحة يدوياً.

يمكن تعيين اختصار مباشر للصق كنص عادي؛ والاختصار الافتراضي المذكور في الوثائق هو Ctrl + Win + Alt + V. كما يمكن تخصيص اختصارات لصيغ أخرى من الإعدادات. راجع المعاينة قبل اللصق، خصوصاً عند تحويل بيانات CSV أو XML إلى JSON، لأن التحويل الآلي قد يغيّر طريقة تمثيل القيم ولا يغني عن فحص البنية الناتجة.

استخراج النص من الصور وتحويل الوسائط محلياً

تتضمن Advanced Paste إجراء Image to text لاستخراج الكلمات من صورة موجودة في الحافظة باستخدام OCR محلي على الجهاز. لا يحتاج هذا الإجراء إلى ربط مزود AI خارجي، وهو مفيد لنسخ نص من لقطة شاشة أو صورة مستند. لكن جودة النتيجة تعتمد على وضوح الصورة واللغة واتجاه النص؛ لذلك راجع الأسماء والأرقام والتواريخ يدوياً قبل استخدامها في معاملة أو تقرير.

تتيح الأداة أيضاً تحويل الصوت أو الفيديو الموجود في الحافظة إلى MP3 أو MP4 بترميز H.264/AAC وفق الخيارات المدعومة في Windows. توضح Microsoft أن عمليات OCR غير المعتمدة على AI وتحويل الوسائط تعمل محلياً ولا تستخدم الذكاء الاصطناعي. لا تفترض أن كل صيغة أو codec ستعمل على كل جهاز؛ فالدعم مرتبط بمكونات Windows والوسائط المدخلة.

Paste with AI: ميزة اختيارية وليست معالجة محلية

تكون ميزة Paste with AI اختيارية ومعطلة افتراضياً. عند تفعيلها وإضافة مزود، تستطيع طلب تلخيص النص المنسوخ أو ترجمته أو إصلاح لغته أو تحويله إلى صيغة محددة. تدعم الإعدادات مزودين عبر الإنترنت مثل OpenAI وAzure OpenAI وMistral وGoogle، إضافة إلى خيارات محلية مثل Ollama وFoundry Local وPhi Silica على أجهزة Copilot+ المدعومة.

عند استخدام مزود عبر الإنترنت، ترسل Advanced Paste نص الحافظة وتعليماتك إلى المزود الذي اخترته. تحتاج بعض الخدمات إلى مفتاح API ورصيد استخدام، وقد تترتب رسوم بحسب النموذج والاستهلاك. أما المزود المحلي فيتطلب تثبيت النموذج وتشغيله على الجهاز، وقد يحتاج إلى ذاكرة ومعالج مناسبين. لا تضع كلمات مرور أو مفاتيح API أو بيانات عملاء في طلب AI دون مراجعة سياسة مزودك.

مثال عملي وسطر أوامر

لتحويل ملف CSV إلى JSON عبر واجهة الأوامر، يمكن استخدام: PowerToys.AdvancedPaste.CLI.exe transform --action json --input people.csv --stdout. ولتحويل HTML إلى Markdown يمكن تمرير الملف إلى الإجراء markdown مع تحديد ملف إخراج. تضيف واجهة CLI فائدة للمطورين الذين يريدون إدخال التحويل في سير عمل محلي أو نص PowerShell بدلاً من فتح النافذة في كل مرة.

تعرض أوامر مثل actions list الإجراءات المتاحة، بينما يعرض providers list --json مزودي AI الذين تم إعدادهم. توضح الوثائق أن قائمة المزودين لا تعرض مفاتيح API ولا تختبر الاتصال ولا ترسل طلبات AI. استخدم --help للتحقق من خيارات الإصدار المثبت لديك؛ فقد تتغير الإجراءات بين الإصدارات.

الخصوصية والقيود ومتى تستخدمها

الفاصل الأمني الأهم هو نوع الإجراء: اللصق العادي وOCR المحلي وتحويل الوسائط لا تتطلب إرسال النص إلى نموذج سحابي، أما Paste with AI فيرسل محتوى الحافظة والطلب إلى المزود المحدد. لذلك اجعل الإجراءات المحلية هي الافتراضية مع المستندات الحساسة، ولا تفعّل AI إلا عند الحاجة وبعد مراجعة شروط المزود ومكان معالجة البيانات. الحافظة نفسها قد تحتوي على آخر كلمة مرور نسختها؛ امسح المحتوى الحساس بعد الانتهاء.

PowerToys أداة Windows وليست تطبيقاً لـ Android أو macOS. كما أن التحويل إلى JSON لا يضمن صحة البيانات المنطقية، وOCR قد يخطئ في الحروف المتشابهة، ومخرجات AI تحتاج مراجعة بشرية. أفضل استخدام لها هو تقليل الخطوات المتكررة وتحويل البيانات البسيطة محلياً، مع إبقاء القرارات الحساسة والتحقق النهائي بيد المستخدم.

English edition

Why give the clipboard its own utility?

Windows clipboard workflows usually stop at copy and paste, but everyday work often requires removing formatting, converting a table to JSON, extracting text from an image, or saving formatted content as a file. Microsoft PowerToys Advanced Paste adds a transformation layer on top of the clipboard, so you do not need to open a separate editor for every small task.

The Advanced Paste window opens with the default shortcut Win + Shift + V. It lets you choose a format or action, and you can assign direct shortcuts to selected operations. The tool is part of the open-source PowerToys suite, not a standalone cloud service; however, some optional features call an AI provider that you configure.

Install PowerToys and check the release

Microsoft's installation documentation supports Windows 11 or Windows 10 version 2004 (build 19041) or later, with an x64 or ARM64 processor. You can install it from Microsoft Store, the official GitHub releases page, or WinGet. In PowerShell, run: winget install --id Microsoft.PowerToys --source winget. After installation, open PowerToys Settings, find Advanced Paste, and enable it.

On the editorial review date, November 24, 2026, the official releases page lists v0.102.3101.0 as the latest stable release, published November 6, 2026, while v0.103 builds appear as development previews. Do not install a Preview build on a work machine merely because its version number is higher. Choose the stable Release and check the releases page when updating this guide because version numbers change.

Transform text without AI

One core action is Paste as Plain Text, which removes formatting copied from websites or Office documents. The tool also supports Markdown and JSON transformations, and can create TXT, HTML, or PNG files depending on the input. For example, you can convert formatted text to Markdown before adding it to a documentation repository, or save copied HTML as a separate file instead of rebuilding the page manually.

You can assign a direct shortcut to plain-text paste; the documented default is Ctrl + Win + Alt + V. Other format shortcuts can be customized in Settings. Review the preview before pasting, especially when converting CSV or XML to JSON, because automated conversion can change how values are represented and does not replace checking the resulting structure.

Extract text from images and convert media locally

Advanced Paste includes an Image to text action that uses local OCR to extract words from an image in the clipboard. It does not require an external AI provider. This is useful for copying text from a screenshot or document photo, but output quality depends on image clarity, language, and text direction. Manually check names, numbers, and dates before using the result in a formal record or report.

The tool can also transcode audio or video content in the clipboard to MP3 or MP4 using H.264/AAC options supported by Windows. Microsoft says the non-AI OCR and media-conversion actions run locally and do not use AI. Do not assume every format or codec will work on every device; support depends on Windows components and the input media.

Paste with AI is optional—not local processing

Paste with AI is optional and disabled by default. After enabling it and adding a provider, you can ask it to summarize copied text, translate it, fix grammar, or transform it into a chosen format. Settings support online providers such as OpenAI, Azure OpenAI, Mistral, and Google, as well as local options such as Ollama, Foundry Local, and Phi Silica on supported Copilot+ PCs.

When you use an online provider, Advanced Paste sends the clipboard text and your prompt to that provider. Some services require an API key and usage credits, and charges may depend on the model and amount of use. A local provider requires the model to be installed and running on your device and may need suitable memory and processing power. Do not put passwords, API keys, or customer data into an AI prompt without reviewing the provider's data policy.

A practical example and the command line

To convert a CSV file to JSON through the command line, use: PowerToys.AdvancedPaste.CLI.exe transform --action json --input people.csv --stdout. To convert HTML to Markdown, pass the file to the markdown action and specify an output file. The CLI is useful for developers who want to add local transformations to a workflow or PowerShell script instead of opening the window each time.

Commands such as actions list show available actions, while providers list --json lists AI providers configured in Settings. Microsoft's documentation says the provider list does not reveal API keys, test connections, or send AI requests. Use --help to check the options supported by your installed release; available actions can change between versions.

Privacy, limits, and when to use it

The most important security distinction is the action type: plain-text paste, local OCR, and media conversion do not require sending text to a cloud model, while Paste with AI sends clipboard content and your prompt to the selected provider. Make local actions the default for sensitive documents. Enable AI only when needed and after reviewing the provider's terms and data-processing practices. The clipboard may also contain the last password you copied, so clear sensitive content when you are done.

PowerToys is a Windows utility, not an Android or macOS app. JSON conversion does not guarantee logical data correctness, OCR can confuse similar characters, and AI output needs human review. Its best use is reducing repetitive steps and converting simple data locally while keeping sensitive decisions and final verification under the user's control.
