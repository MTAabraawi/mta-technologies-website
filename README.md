# MTA TECHNOLOGIES - Official Corporate Website
**BUILDING A SMARTER TOMORROW**  
**البريد الرسمي المعتمد: mtatechnologies0@gmail.com**

الموقع الرسمي لشركة **MTA TECHNOLOGIES**. يتكون من صفحات HTML وCSS وJavaScript، مع **Cloudflare Pages Functions** لتقديم صفحات المتاجر وتفاصيل التطبيقات من جهة الخادم، وواجهة وسيطة للوصول إلى محرك فهرس التطبيقات. لذلك فإن الاستضافة الإنتاجية المعتمدة هي **Cloudflare Pages**؛ فتح الملفات مباشرة أو استضافتها على GitHub Pages لا يوفر وظائف الكتالوج الديناميكي.

---

## 📁 محتويات الحزمة البرمجية (File Structure)

- `index.html` : الصفحة الرئيسية مع الشعار الرسمي، الرسالة، وملخص المشاريع والمجالات.
- `about.html` : نبذة عن الشركة ورؤيتها ورسالتها.
- `projects.html` : المشاريع والمنتجات الرسمية (MTA Net Blocker, MTA AI Video Studio, MTA Video Downloader, MTA University Library Collector).
- `innovation.html` : مجالات العمل والابتكار التقني السبعة.
- `knowledge.html` : مركز المعرفة والمقالات الهندسية الأصلية.
- `gallery.html` : معرض الهوية البصرية والواجهات مع عارض تكبير تفاعلي (Lightbox).
- `contact.html` : صفحة التواصل والبريد المعتمد `mtatechnologies0@gmail.com`.
- `404.html` : صفحة الخطأ 404 المخصصة لشبكات الاستضافة السحابية.
- `privacy-policy.html` : سياسة الخصوصية الشاملة وملفات تعريف الارتباط.
- `terms.html` : شروط الاستخدام وحقوق الملكية الفكرية.
- `disclaimer.html` : إخلاء المسؤولية القانونية وحالة النماذج الأولية.
- `cookies.html` : سياسة ملفات تعريف الارتباط والتخزين المحلي.
- `css/style.css` : نظام التصميم المتكامل (Dark/Light mode + دعم RTL/LTR التلقائي).
- `js/main.js` : منطق التبديل اللحظي بين العربية والإنجليزية، وتغيير النمط، وتكبير الصور.
- `images/` : ملفات الشعارات الرسمية المتجهة (SVG) بدقة فائقة.
- `favicon.svg` : أيقونة المتصفح الرسمية.
- `robots.txt` : تعليمات محركات البحث.
- `sitemap.xml` وملفات Sitemap المساندة : خرائط عناوين الصفحات العامة.
- `functions/` : وظائف Cloudflare لمعالجة صفحات المتاجر وتفاصيل التطبيقات وتقديم بياناتها في HTML الأولي.
- `tests/e2e/` و`playwright.config.js` : اختبارات متصفح آلية للكتالوج والصفحات وSEO.

## ⚡ طرق النشر والاستضافة السريعة

### 1. معاينة الملفات الثابتة
يمكن فتح `index.html` محلياً لمراجعة التصميم الأساسي فقط. لن تعمل صفحات الكتالوج الديناميكي وعمليات SSR وواجهات `/api/` دون تشغيل بيئة Cloudflare Pages محلية وربط محرك بيانات تجريبي أو فعلي.

### 2. النشر على Cloudflare Pages (بيئة الإنتاج المعتمدة)
يتم النشر من مستودع GitHub المرتبط بمشروع Cloudflare Pages، مع تفعيل مجلد `functions/` وإعداد متغيرات البيئة اللازمة لمحرك التطبيقات. لا تستخدم الرفع المباشر لنسخة ثابتة إذا كان المطلوب تشغيل الكتالوج ووظائف SSR.

### ملاحظة حول GitHub Pages
GitHub Pages لا يشغّل Cloudflare Pages Functions؛ لذلك لا يُعد بديلاً مكافئاً لبيئة الإنتاج الحالية. يمكن استخدامه لنسخة ثابتة تجريبية فقط بعد فصل الوظائف الديناميكية بوضوح.

## الاختبارات الآلية

يتضمن المستودع اختبارات Playwright تُشغّل على Cloudflare Pages محلياً مع خادم بيانات تجريبي، ولا تحتاج إلى زيارات اختبار على الموقع الإنتاجي.

```bash
npm install
npx playwright install chromium
npm run test:e2e
```

تشمل التغطية الحالية تدفق المتاجر والكتالوج، العرض الأولي من جهة الخادم، التحميل التلقائي والصفحات التفصيلية، الروابط الداخلية، عناوين SEO وCanonical وJSON-LD، استجابة 404، وفحص إزالة أكواد الشبكات الإعلانية القديمة. تحظر الاختبارات طلبات Google Analytics وAdSense وشبكات الإعلانات الخارجية، ولا تنفذ نقرات أو زيارات إعلانية اصطناعية.
