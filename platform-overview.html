MTA APPS CENTER / PLATFORM OVERVIEW

منصة لاكتشاف البرامج عبر مصادر متعددةA multi-source software discovery platform

يجمع MTA Apps Center بيانات وصفية من كتالوجات عامة متعددة، وينظمها في دليل قابل للبحث والتصفية والتصفح. تعرض كل نتيجة مصدرها الأصلي، وتبقى صفحة الناشر هي المرجع النهائي للتنزيل والتوافق والسعر.MTA Apps Center aggregates metadata from multiple public catalogues and organizes it into a searchable, filterable directory. Each result retains its original source; the publisher listing remains authoritative for downloads, compatibility and pricing.

ما الذي توفره المنصة؟What the platform provides

يوفر الدليل صفحات مستقلة للمصادر، وبطاقات للتطبيقات، وصفحات تفاصيل ديناميكية، وروابط إلى صفحات الناشرين. وتُعرض الحقول المتاحة مثل الاسم والوصف والمطور والتصنيف والمنصة والترخيص والإصدار والأيقونة عندما يتيحها المصدر.The directory provides source-specific pages, application cards, dynamic detail pages and links to publisher listings. Available fields can include name, description, developer, category, platform, licence, version and icon when supplied by the source.

كيف تنتقل البيانات؟How data moves through the system
  1. مصادر عامة: واجهات بحث وفهارس رسمية أو عامة للمتاجر والمشروعات.Public sources: official or public search interfaces and catalogues.
  2. موصلات مستقلة: يجلب كل موصل الحقول المتاحة من مصدره مع عزل فشل أي مصدر عن بقية المصادر.Independent connectors: each connector collects available fields while isolating failures from other sources.
  3. توحيد وفهرسة: تُوحّد السجلات وتُحفظ هويات المصدر والمعرّفات وروابط الصفحات الأصلية.Normalization and indexing: records are normalized while source identities, IDs and original listing URLs are retained.
  4. قاعدة GitHub: تُحفظ لقطات بيانات JSON وفهارس البحث والتصفح في مستودع البيانات.GitHub-backed catalogue: JSON snapshots and search/browse indexes are stored in the catalogue repository.
  5. واجهة المحرك والموقع: يقدم المحرك واجهة API، ثم يعرض موقع MTA النتائج وصفحات المتاجر والتطبيقات.Engine and website: the engine exposes an API, and the MTA site renders results, store pages and application details.
حدود التغطية وجودة البياناتCoverage and data quality

لا تعني إضافة متجر أن كامل محتواه أصبح مفهرساً. تتحدد التغطية بحدود واجهة المصدر والبحث والترقيم وسياسات الاستخدام والإتاحة الإقليمية. قد تغيب بعض الحقول أو تتأخر تحديثاتها؛ لذلك لا يعرض MTA الحقول غير المتوفرة كحقائق مؤكدة، ويوجه المستخدم إلى صفحة المصدر للتحقق النهائي.Adding a store does not mean its entire catalogue is indexed. Coverage is bounded by source APIs, search and pagination limits, terms of use and regional availability. Some fields may be missing or stale, so MTA does not present unavailable fields as verified facts and directs users to the original listing for final confirmation.

الملكية والحقوق ونطاق الأصولOwnership, rights and asset scope
  • تظل التطبيقات والعلامات التجارية والشعارات والصفحات الأصلية مملوكة لأصحابها، ولا يدعي MTA ملكيتها لمجرد فهرستها أو الربط إليها.Applications, trademarks, logos and original listings remain with their respective owners. Listing or linking to them does not make them MTA property.
  • لا يفترض MTA أن المستودع العام مرخص بMIT لمجرد أنه متاح للعامة؛ يجب مراجعة ملف LICENSE لكل مستودع. وإذا كانت نسخة منشورة تحت MIT أو ترخيص مفتوح مماثل، تبقى حقوق الاستخدام الممنوحة للنسخ السابقة قائمة، ولا يمكن بيع تلك النسخ على أنها حصرية لمشترٍ واحد.MTA does not assume that a public repository is MIT-licensed merely because it is public; the LICENSE file of each repository must be checked. If a version has been released under MIT or a similar open licence, rights already granted for those copies remain in force, and those copies cannot be sold as exclusive to one buyer.
  • عند تقييم شراكة أو نقل أصول، يجب فصل قيمة النطاق والعلامة والمحتوى الأصلي وقاعدة الفهرسة والموصلات ووثائق التشغيل عن الشفرة المفتوحة والبيانات التابعة لمصادر خارجية.For a partnership or asset transfer review, distinguish the domain, brand, original content, indexing data, connectors and operating documentation from open-source code and third-party data.
  • تخضع البيانات الوصفية وروابط المصادر لشروط المصادر الأصلية. يجب التحقق من حقوق الاستخدام والنقل لكل مصدر قبل أي صفقة أو إعادة توزيع.Metadata and source links remain subject to upstream terms. Usage and transfer rights must be checked for each source before any transaction or redistribution.
  • يتطلب نقل النطاق والعلامة والمحتوى الأصلي وبيئة الاستضافة والمستودعات والحسابات موافقات وإجراءات مستقلة من المالكين ومزودي الخدمات، ولا تنتقل حسابات الأطراف الثالثة تلقائياً.Transferring the domain, brand, original content, hosting, repositories and service accounts requires separate owner approvals and provider processes; third-party accounts do not transfer automatically.
  • لا تُعرض أرقام الزيارات أو الإيرادات أو نتائج الاختبارات كضمانات. ينبغي إرفاق كل رقم بتاريخ ونطاق ومصدر قابل للتحقق، كما يجب ربط عدد الاختبارات بإصدار مجموعة الاختبار والتشغيل المحدد.Traffic, revenue and test results are not guarantees. Each metric should include a verifiable date, scope and source; test counts must identify the test-suite version and specific run.
الشفافية التشغيليةOperational transparency

تتغير حالة كل مصدر بحسب نجاح المزامنة وتوفر سجلاته. وتظهر حالة المصدر وعدد السجلات المفهرسة عندما تتوفر إحصاءات موثوقة. لا نَعِد بتوفر دائم لمصدر خارجي أو بتمثيل كامل لكل متجر.Each source status depends on synchronization and record availability. Source state and indexed counts are shown when reliable statistics are available. MTA does not promise uninterrupted upstream availability or complete representation of every store.
